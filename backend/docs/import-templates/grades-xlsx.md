# Импорт оценок (grades-xlsx)

## Endpoint
POST /api/admin/import/grades-xlsx

## Параметры
- `file` (required): Файл XLSX/XLS (макс. 10MB)
- `dryRun` (optional, boolean): Если `true`, проверяет данные без записи в БД

## Формат файла

### Колонки (в порядке):
1. **date** (обязательно) - Дата урока в формате YYYY-MM-DD
2. **group** (обязательно) - Название группы
3. **subject** (обязательно) - Название предмета
4. **student_email** (обязательно) - Email студента
5. **grade_value** (обязательно) - Оценка (1-5)
6. **weight** (опционально) - Вес оценки (0-100), по умолчанию 1.0
7. **comment** (опционально) - Комментарий (макс. 1000 символов)
8. **teacher_email** (опционально) - Email преподавателя, который поставил оценку (по умолчанию текущий пользователь)

### Пример:
```
date        | group      | subject    | student_email      | grade_value | weight | comment        | teacher_email
2024-01-15  | Группа-1   | Математика | student@example.com| 5          | 1.0    | Отлично        | teacher@example.com
2024-01-15  | Группа-1   | Математика | student2@example.com| 4         | 1.0    | Хорошо         |
```

### Валидация:
- `date`: обязательное поле, формат даты (YYYY-MM-DD)
- `group`: обязательное поле, должна существовать в системе
- `subject`: обязательное поле, должен существовать в системе
- `student_email`: обязательное поле, валидный email, студент должен существовать в системе
- `grade_value`: обязательное поле, число от 1 до 5
- `weight`: опционально, число от 0 до 100
- `comment`: опционально, максимум 1000 символов
- `teacher_email`: опционально, валидный email, преподаватель должен существовать в системе

### Логика:
- Система ищет урок по дате, группе и предмету
- Если урок не найден, создаётся новая позиция расписания и урок
- Если оценка уже существует, она обновляется

### Ответ при успехе:
```json
{
  "message": "Импорт успешно завершен",
  "dry_run": false,
  "success_count": 10
}
```

### Ответ при ошибках:
```json
{
  "message": "Импорт завершен с ошибками",
  "dry_run": false,
  "success_count": 8,
  "errors": [
    {
      "row": 3,
      "message": "Студент не найден: wrong@example.com"
    },
    {
      "row": 5,
      "message": "Оценка должна быть от 1 до 5"
    }
  ]
}
```
