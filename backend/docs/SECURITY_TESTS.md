# Security Test Suite - Object-Level Access Leaks

## Описание

Набор тестов для проверки безопасности на уровне объектов. Проверяет что пользователи не могут получить доступ к данным других тенантов или пользователей.

## Запуск тестов

```bash
# Все тесты безопасности
php artisan test --filter ObjectLevelAccess

# Конкретный тест
php artisan test --filter test_user_cannot_access_other_tenant_groups

# С покрытием
php artisan test --coverage --filter ObjectLevelAccess
```

## Покрытые сценарии

### 1. Изоляция по tenant_id

- ✅ Пользователь не может получить доступ к группам другого тенанта
- ✅ Пользователь не может получить доступ к урокам другого тенанта
- ✅ Пользователь не может получить доступ к оценкам другого тенанта
- ✅ Пользователь не может получить доступ к документам другого тенанта
- ✅ Пользователь не может получить доступ к журналу другого тенанта

### 2. Изоляция по user_id

- ✅ Пользователь не может получить доступ к уведомлениям другого пользователя
- ✅ Список уведомлений фильтруется по user_id

### 3. CRUD операции

- ✅ Пользователь не может создать ресурс с tenant_id другого тенанта
- ✅ Пользователь не может обновить ресурс другого тенанта
- ✅ Пользователь не может удалить ресурс другого тенанта

### 4. SQL Injection защита

- ✅ SQL injection через параметры не работает
- ✅ Прямой SQL injection через tenant_id не работает

### 5. Массовые операции

- ✅ Массовые операции не затрагивают данные другого тенанта

### 6. Перечисление ID

- ✅ Прямой доступ через ID перечисления не раскрывает данные

## Структура тестов

### ObjectLevelAccessTest.php

Базовые тесты на object-level доступ для основных сущностей.

### ObjectLevelAccessLeakTest.php

Расширенный набор тестов на утечки данных:
- Фильтрация списков
- Блокировка прямого доступа
- Защита от подмены tenant_id
- Защита от SQL injection
- Защита массовых операций
