# ГОСТ-документы: Приказы и Распоряжения

## Описание

Система генерации документов (приказы и распоряжения) согласно ГОСТ Р 6.30-2003.

## Требования

### Зависимости

1. **PhpOffice/PhpWord** - для работы с DOCX шаблонами
   ```bash
   composer require phpoffice/phpword
   ```

2. **LibreOffice** - для конвертации DOCX в PDF (установка на сервере)
   ```bash
   # Ubuntu/Debian
   sudo apt-get install libreoffice

   # Windows - скачать с официального сайта
   ```

### Настройка Storage

В `config/filesystems.php` добавить диски:

```php
'templates' => [
    'driver' => 'local',
    'root' => storage_path('app/templates'),
],

'documents' => [
    'driver' => 'local',
    'root' => storage_path('app/documents'),
],
```

## Структура шаблонов

Шаблоны DOCX должны содержать переменные в формате `${variable_name}`:

Пример переменных для приказа:
- `${number}` - номер приказа
- `${date}` - дата в формате ДД.ММ.ГГГГ
- `${title}` - заголовок
- `${content}` - содержание приказа
- `${signer}` - подписант
- `${approver}` - согласующий (опционально)

## API Endpoints

### GET /api/gost-documents/templates
Получить список доступных шаблонов

### POST /api/gost-documents/orders
Генерация приказа

**Request:**
```json
{
  "number": "123-п",
  "date": "15.01.2024",
  "title": "О назначении ответственного",
  "content": "Назначить ответственным...",
  "signer": "Директор Иванов И.И.",
  "approver": "Заместитель Петров П.П."
}
```

### POST /api/gost-documents/decrees
Генерация распоряжения

**Request:**
```json
{
  "number": "45",
  "date": "20.01.2024",
  "title": "О проведении мероприятия",
  "content": "Провести мероприятие...",
  "signer": "Руководитель Сидоров С.С."
}
```

### GET /api/gost-documents/{id}
Получить информацию о документе

## Валидация по ГОСТ

### Формат номера
- Приказ: `число` или `число-буква` (например: `123` или `123-п`)
- Распоряжение: аналогично

### Формат даты
- ДД.ММ.ГГГГ (например: `15.01.2024`)

### Обязательные поля
- `number` - номер документа
- `date` - дата
- `title` - заголовок
- `content` - содержание
